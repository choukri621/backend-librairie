# Projet Livres Gourmands - Étude de cas H2026

Projet final de développement web (Programmation Web avancée).

## Fonctionnalités implémentées
- [x] Interface React avec navigation par pages.
- [x] Affichage dynamique des ouvrages depuis l'API.
- [x] Gestion du panier (ajout/suppression, persistance via localStorage).
- [x] CRUD complet pour l'administration des ouvrages.
- [x] Dossier de conception inclus dans le répertoire `/conception`.

## Installation
1. Backend : `cd backend && npm install && node app.js`
2. Frontend : `cd frontend && npm install && npm start`

## Technologies
- Frontend : React, Bootstrap, Axios, Context API
- Backend : Node.js, Express, MySQL

# Backend Librairie

## 1. Présentation du projet
Ce projet est une API REST pour la gestion d’une librairie en ligne.  
Il permet la gestion des utilisateurs, ouvrages, catégories, commandes et panier.

Technologies utilisées : Node.js, Express, MySQL, JWT, Bcrypt.
